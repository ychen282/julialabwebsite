# julialabwebsite
lab website

Website Update Guide (written by YC on 20250910, for basic website management going forward)
1. Create and Upload relevant images to the "uploads" folder, if any
3. Create a test.html under gh-pages, or reuse an existing one
4. Copy the code of specific page to be updated to the test.html
5. Copy the existing code and modify the text and url to the images
6. Click commit changes
7. Monitor the progress of the commit. Once appearing "3/3", indicating completion of the commitment, check the look of the webpage by going to https://burnierlab.ca/test.html
8. Check on both computer and phone screens to make sure the layouts are good
9. If all looks good. Copy the entire code from test.html to the intended webpage (replace the entire code), and commit changes

Notes:
1. There can be some delay for the updates to appear live, due to browser's cache. Check again after a few minute/hours, or check on new browsers/devices
